# সাব্বির AI (Sabbir AI)

A separate native Android starter project for a Bengali voice assistant. This repository is independent of Rubel Telecom and does not use its code, Appwrite project, or database.

## Build APK
1. Open the **Actions** tab.
2. Select **Build Sabbir AI APK** and press **Run workflow** (or push a commit to trigger it).
3. When the workflow finishes, open the run and download the `Sabbir-AI-debug-apk` artifact.

This is an early prototype, not a finished always-on personal assistant. Background microphone access depends on Android permissions and battery settings. Speaker identity verification, Gemini/AI conversation, and safe phone-action controls are not implemented yet. Test the APK before relying on it.
